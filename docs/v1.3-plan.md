# Sooda v1.3 — implementation plan & frozen contracts

Status: contracts frozen at Phase 0. Any later change to a signature below is recorded in
"Decisions & deviations" at the bottom.

## Global rules

* TypeScript strict, no `any`, no `@ts-ignore`.
* **All money/percent math lives in pure functions under `src/lib/`.** UI formats, never computes.
* **Rounding rule (universal): intermediate math stays at full float precision; `round2()` is
  applied only to values returned from an exported function.** Every test vector in the brief was
  re-derived numerically under this rule and matches — see `docs/v1.3-baseline.md` methodology.
* Percent-vs-fraction convention: any identifier ending in `Percent` is `0..100`. Anything called
  a `rate` or `fraction` is `0..1`. Functions never silently accept both.
* No new runtime dependencies. No network calls. Nothing fetched at runtime.

Required vectors (annual 40 %, tol 0.01): `r=0.028436`; `R(1e5,3)=108775.73`;
`S*(R,20)=130530.88`; `realProfitPercent(120000,R)=10.32`.
Edges: `m=0 ⇒ R=c`; deflation; `annual=0`; user-supplied R path; `MAX_VALUE` stays finite.

## Decisions & deviations

* **D1 — Parallel lanes run in the shared working tree, not git worktrees.** The four Phase 2
  lanes own strictly disjoint files, so there is nothing to merge; worktrees would add branch
  juggling for no conflict reduction. Each lane is instructed not to run repo-wide `typecheck`
  or `build` (they would see other lanes' half-written files) and not to edit outside its list.
  The lead reviews every diff before committing.
* **D2 — No Jalali utility existed.** The brief assumed one. `src/lib/dates.ts` is new and wraps
  `Intl.DateTimeFormat('fa-IR')`, whose default calendar is already `persian`. No dependency added.
* **D3 — `round2` at the output boundary only.** Applying it to intermediates changes
  `calcInstallmentReverse`'s `presentValue` to 10709252.30 and misses the briefed 10709252.29.
